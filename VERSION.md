# AURA AI — Version

**Current: 1.0.0**

This file tracks the project's *actual maturity* toward the Version 1.0 milestone defined in
[docs/TODO_V1.md](docs/TODO_V1.md). `app/build.gradle.kts`'s `versionName` is kept in sync with the
number here.

## Why 1.0.0 now, and what it does and doesn't mean

`app/build.gradle.kts` had declared `versionName = "1.0.0"` since Phase 1, before most of the
platform existed and before it was known the project had never actually been compiled (see
[docs/TODO_V1.md §0](docs/TODO_V1.md#0-foundation--found-broken-fixed-this-session)). That number
described intent, not state, so every version in the history below was corrected to match reality
instead — `1.0.0` was explicitly reserved for the point where every Critical item in
`docs/TODO_V1.md` §2 is actually done. As of 0.19.0-dev, all ten are. This version number reflects
that specific, checkable claim — not "production-perfect" or "nothing left to do": the same
`docs/TODO_V1.md` that defines this threshold also lists real High/Medium/Low items deliberately
left for afterward (§3–§5), and `docs/PRODUCTION_RELEASE.md` §6 lists what's genuinely blocked on
the app's publisher (a release keystore, a Play Console account) rather than on more engineering.
See [`AURA_V1_COMPLETION_REPORT.md`](AURA_V1_COMPLETION_REPORT.md) for the full picture: what
shipped, what's verified, what's still open, and what to do next.
